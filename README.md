# Credit Scoring Default Prediction Pipeline

End-to-end ML pipeline for predicting credit card default risk.

## Project Structure

- `src/` - Source code (data, models, api, monitoring)
- `tests/` - Pytest unit tests
- `data/` - Data storage (DVC tracked)
- `mlruns/` - MLflow tracking server

## How to run

### 1. Install dependencies

```bash
pip install -r requirements.txt
```
